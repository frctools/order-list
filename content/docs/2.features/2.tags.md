# Using Tags

Tags help you organize and filter the parts your team is buying.

## What are Tags?

Tags are customizable labels applied to **parts**, not to whole orders. That is
the useful way round: an order is one vendor's checkout, and the parts inside it
can belong to completely different subsystems. Tagging the part means the
drivetrain lead can find their parts wherever they were bought.

Each tag has:

- A **name** - Descriptive label (e.g., "Electronics", "Mechanical", "Urgent")
- A **color** - Visual identifier for quick recognition

Tags are organization-specific, meaning each organization has its own set of tags. Only organization **admins** and **owners** can create and manage tags.

## Creating Tags

To create a new tag:

1. Open [Organization Settings](/organization)
2. Open the **Tags** tab
3. Click <UButton color="primary" icon="i-lucide-plus" size="xs">New Tag</UButton>
4. Enter a **name** for the tag
5. Choose a **color**
6. Click **Create tag**

::tip
Use colors strategically - by making them visually distinct and meaningful, you can quickly identify and categorize orders at a glance.
::

## Applying Tags to Parts

When adding or editing a part:

1. Look for the **Tags** field
2. Click to open the tag selector
3. Select one or more tags to apply

Any member can tag a part. Creating and deleting the tags themselves is limited
to admins and owners.

## Filtering by Tag

In the table view, use the tag filter above the table. Only parts carrying the
selected tags are shown — and **Export CSV** exports exactly what the filters
leave on screen, which makes a tag a quick way to produce a list of everything
one subteam has ordered.

## Deleting Tags

To delete a tag:

1. Go to the Tags management area in [Organization Settings](/organization)
2. Click on the tag to edit
3. Click <UButton color="error" variant="subtle" icon="i-lucide-trash" size="xs">Delete</UButton>
4. Confirm the deletion

::warning
Deleting a tag removes it from every part carrying it. This cannot be undone —
though the parts themselves are untouched.
::

## Tag Best Practices

Here are some suggestions for organizing tags:

### By Subteam

- `Electronics`
- `Mechanical`
- `Programming`
- `Carpentry`

### By Priority

- `Urgent`
- `High Priority`
- `Nice to Have`

### By Subsystem

- `Drivetrain`
- `Intake`
- `Shooter`
- `Climber`

### By Status

- `Mentor Approved`
- `Awaiting Approval`

::tip
Start with a small set of tags and add more as needed. Too many tags can make filtering less effective.
::
